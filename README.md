# Miniapp

Mini aplicaciones de un solo archivo HTML. No necesitan instalación ni
servidor: se abren con doble clic en el `index.html` de cada carpeta (o
`Tactical_Medic.html`) y guardan sus datos en el propio navegador.

| Carpeta | Qué es |
|---|---|
| [`cafeteria/`](cafeteria/) | Control de consumos y gastos de los clientes de una cafetería, con listado en PDF a fin de mes. |
| [`calendario/`](calendario/) | Calendario anual para anotar tareas, eventos y gastos, con el total de cada mes. |
| [`gastos/`](gastos/) | Agenda y Gastos: calendario anual con anotaciones por colores, gastos (también mensuales recurrentes), suma por mes y gráfica del año. |
| [`mapa-osint/`](mapa-osint/) | OSINTMap: mapa de fuentes abiertas para seleccionar regiones, cargar y marcar elementos y exportarlos a ATAK y otras herramientas SIG. |
| [`tactical-medic/`](tactical-medic/) | Tactical Medic: guía de consulta con pestañas de Protocolos y DNBI. |

Venían de ramas sueltas del repositorio de OpoFit (antes NUTRIAPP); aquí está
la última versión de cada una.
